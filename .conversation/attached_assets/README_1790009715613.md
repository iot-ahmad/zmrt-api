# 🍓 زمرت — لعبة الفواكه

نسخة إلكترونية أولية من لعبة الفواكه الورقية.

- 3 إلى 8 لاعبين
- كل لاعب يبدأ بعدد أوراق يساوي عدد اللاعبين
- تمرير الأوراق
- خصوم آليون
- زر «زمرت!» والتحقق من المجموعة
- النقاط: 100، 90، 80... حسب الترتيب
- واجهة موبايل مع حركة اختيار الأوراق

هذه النسخة Prototype محلية ضد AI. المرحلة التالية يمكن تطويرها إلى Multiplayer حقيقية باستخدام WebSocket/Socket.IO.
